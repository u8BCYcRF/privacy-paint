# Privacy Paint

画像をサーバーへ送信せず、ブラウザ内だけでモザイク、ぼかし、塗りつぶし、テキスト、画像の上乗せを行う静的画像エディターのプロトタイプです。

## 起動

ビルドや依存パッケージのインストールは不要です。Node.jsで開発サーバーを起動できます。

```sh
npm run dev
```

ブラウザで `http://127.0.0.1:4173` を開きます。`?demo` を付けるとサンプル画像を読み込んだ状態で起動できます。

ポートを変更する場合は、たとえば `PORT=8000 npm run dev` と指定します。

## 操作

- 画像を選択、ドロップ、またはクリップボードから貼り付け
- モザイクとぼかしは、ブラシの太さと効果の強さを選んで隠したい場所をなぞる
- 塗りつぶしは、隠したい範囲をドラッグ
- テキストは設定欄に入力してから配置場所をクリック
- 上乗せ画像は「画像」ツールから選択
- 「選択」ツールで加工を移動・拡大縮小・削除
- PNG、JPG、WebPで書き出し

画像処理はすべてCanvas APIで行い、画像データを外部へ送信しません。
